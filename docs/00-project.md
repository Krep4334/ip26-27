# Паспорт проекта «Учебный прокат»

**Происхождение:** новый учебный проект. **Команда:** индивидуальная работа, студент отвечает за анализ, реализацию и тестирование. **Лицензия:** MIT.

Приложение помогает студентам закрепить за собой доступный проектор, микрофон или ноутбук. Ответственный за выдачу видит брони и фиксирует передачу и возврат оборудования. Три основные функции — каталог, бронирование и управление выдачей.

Стек: Python 3.13.5, SQLite из стандартной библиотеки, Git, GitHub Actions. Отдельная система сборки и внешние сервисы не требуются.

## Структура проекта

Точка входа — `python -m src.equipment`. В `src/equipment/__main__.py` определены команды, валидация и транзакции. `docs/` содержит документацию и модели, `tests/` предназначен для тестов. Версия Python и зависимости фиксируются в `.python-version` и `requirements.txt`.

SQLite хранит три сущности — студент, оборудование, бронь. Параметр `--db` задаёт файл базы, по умолчанию `equipment.sqlite3`. При первом запуске создаются таблицы и три демонстрационных устройства.
