# Контракт команды бронирования

Команда `book` реализует [FR-2 и сценарий US-2](01-requirements.md#us-2--fr-2--есть). Студент вызывает её из терминала. Другая программа может запустить тот же процесс и обработать код завершения и JSON. [Реализация команды](../src/equipment/__main__.py).

## Вызов

Из корня проекта с Python 3.13.5:

```sh
python -m src.equipment [--db PATH] book --student STUDENT_ID --equipment EQUIPMENT_ID
```

| Параметр | Тип | Условия |
|---|---|---|
| `--db PATH` | Путь к файлу SQLite | Необязательный. Передаётся до `book`. По умолчанию `equipment.sqlite3` в текущем каталоге. Родительский каталог должен существовать и разрешать запись. |
| `--student STUDENT_ID` | Целое число | Обязательный. От 1 до 9223372036854775807. При первой успешной брони студент с таким номером добавляется в базу. |
| `--equipment EQUIPMENT_ID` | Целое число | Обязательный. От 1 до 9223372036854775807. Для успеха требуется существующее свободное устройство. Его идентификатор можно получить командой `catalog`. |

## Результат

- **Код 0.** В stdout приходит JSON-объект в UTF-8 с целыми полями `id`, `student_id`, `equipment_id` и строковым полем `status` со значением `reserved`. В SQLite появляется ровно одна бронь, устройство становится недоступным.
- **Код 4.** В stderr приходит JSON `{"error": "equipment_unavailable"}`, stdout остаётся пустым. Активная бронь уже есть, поэтому новая запись не создаётся.

Также CLI возвращает код 2 и текст диагностики argparse при некорректных аргументах, код 3 с JSON `{"error": "equipment_not_found"}` для неизвестного устройства или код 5 с JSON `{"error": "database_error"}` при ошибке SQLite.

## Примеры

### Успех

Файл `contract.sqlite3` ещё не существует. Инициализация создаёт проектор № 1, и вызов бронирует его для студента № 7.

```sh
python -m src.equipment --db contract.sqlite3 book --student 7 --equipment 1
```

Код завершения 0, stdout:

```json
{"id": 1, "student_id": 7, "equipment_id": 1, "status": "reserved"}
```

### Устройство занято

После первого примера используется тот же файл базы. Студент № 8 запрашивает уже забронированный проектор.

```sh
python -m src.equipment --db contract.sqlite3 book --student 8 --equipment 1
```

Код завершения 4, stderr:

```json
{"error": "equipment_unavailable"}
```

Бронь № 1 остаётся за студентом № 7.
