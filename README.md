# Учебный прокат

Локальное приложение для бронирования учебного оборудования.

## Запуск

Требуется Python 3.13.5. Из корня проекта на новой базе выполните:

```sh
python -m pip install -r requirements.txt
python -m src.equipment --db demo.sqlite3 catalog
python -m src.equipment --db demo.sqlite3 book --student 7 --equipment 1
python -m src.equipment --db demo.sqlite3 my-bookings --student 7
```

Каталог показывает проектор, микрофон и ноутбук. Бронирование возвращает бронь № 1 со статусом `reserved`, а последняя команда показывает её для студента 7.

[Паспорт проекта](docs/00-project.md)

15.11.2026 Codex проверил команды на Windows с Python 3.13.5 и новым файлом SQLite.

## Статус требований

| № | Функция или ограничение | Приоритет | Состояние |
|---|---|---|---|
| FR-1 | Студент может просматривать каталог оборудования и видеть доступность | Обязательно | Есть |
| FR-2 | Студент может бронировать доступное оборудование | Обязательно | Есть |
| FR-3 | Студент может просматривать свои брони по идентификатору студента | Обязательно | Есть |
| FR-4 | Студент может отменять свою бронь до выдачи | Обязательно | Нужно сделать |
| FR-5 | Ответственный может просматривать список броней всех студентов | Обязательно | Нужно сделать |
| FR-6 | Ответственный может фиксировать выдачу и возврат оборудования по брони | Обязательно | Нужно сделать |
| NFR-1 | Python 3.13.5, без сторонних библиотек | Обязательно | Есть |
| NFR-2 | Хранение между запусками в SQLite | Обязательно | Есть |
| NFR-3 | Одна активная бронь на устройство | Обязательно | Есть для текущих статусов |
